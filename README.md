# Movie Database 🎬

A full-stack movie database application built with React for the frontend and Node.js/Express for the backend.

## Short Description
Movie Database – Manage and interact with movies, including authentication, comments, ratings, favorites, user statistics, and actor details.

## Features
- **Authentication:** Users can sign up and log in to interact with the app.  
- **Comments:** Users can leave comments on movies and view comments from others.  
- **Ratings:** Users can rate movies and see aggregate ratings.  
- **Favorites:** Add movies to your personal favorites list.  
- **Search & Filter:** Search movies by title and filter by rating or category.  
- **Error Handling:** Users can send error reports when something goes wrong; the app shows messages when movies fail to load or an action fails.  
- **Profile Page / User Stats:** Users have a profile page showing:
  - Registration date  
  - Number of comments made  
  - Number of movies added to favorites  
  - Number of ratings given  
- **Skeleton Loading:** Displays loading placeholders while data is being fetched for a smooth user experience.  
- **Actors Page:** View actor details including biography, filmography, and related movies.  
- **Get User Activity:** View comments and ratings per movie you added.
